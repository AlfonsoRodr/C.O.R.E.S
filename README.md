# C.O.R.E.S
C.O.R.E.S. is a production-grade, B2B SaaS platform designed to ingest, process, and analyze heavy enterprise reports using AI. It transforms unstructured business documents into structured, actionable insights (KPIs, percentages, and summaries) wrapped in a secure, scalable cloud architecture.

## Stack

- Spring Boot
- PostgreSQL
- Astro
- Redys
- Cloudflare Tunnels (cloudflared) y Cloudflare WAF
- AI Agent
- Stripe
- Docker
- Kubernetes
